Telegram Habit Tracker Bot 🚀

Умный Telegram-бот для отслеживания ежедневных привычек, написанный на Python.

🛠 Технологии
- Python 3.10+
- aiogram 3 (асинхронный фреймворк для Telegram Bot API)
- aiosqlite (асинхронная база данных SQLite)
- FSM (конечные автоматы для диалогов)

 ✨ Функционал
- ➕ Добавление новых привычек
- 📊 Просмотр списка всех привычек
- 🗑️ Интерактивное удаление привычек
- ❌ Отмена ввода
- 💾 Хранение данных в базе SQLite
